# World Cocoa Foundation Website Modernization

This project involves the modernization of the World Cocoa Foundation website, transitioning it from a monolithic single-page structure to a multi-page, premium, and card-less architecture.

## Architecture
- **Multi-Page**: Dedicated pages for Home, About, Our Work, Sustainability, Farmers, News, and Contact.
- **Externalized Assets**: All CSS and JS are decoupled into `css/main.css` and `js/main.js` for better maintainability.
- **Modern UI**: Clean, whitespace-driven design with premium typography and cocoa-inspired color themes.
- **Theme Support**: Seamless Light/Dark mode transitions with persistence.

## Technologies Used
- HTML5 & CSS3 (Custom Variables, Flexbox, Grid)
- Vanilla JavaScript
- FontAwesome 6 (Icons)
- AOS (Animate On Scroll)
- Google Fonts (Playfair Display, Source Sans 3)

## Features
- Standardized Global Header & Footer.
- Interactive Donation Modal.
- Scroll-triggered animations for engagement.
- High-contrast, accessibility-focused navigation.

## Directory Structure
- `/` - HTML Root Pages
- `/css/` - Style Definitions
- `/js/` - Application Logic
- `/img/` - Visual Assets
